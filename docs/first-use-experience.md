# First-use experience

- Welcome introduces the video/HDR and subtitle controls, music/equalizer/background playback, built-in browser/filtering/skipping/downloads, file/archive/recycle tools, personal connections, themes and library customisation. It does not promise universal codecs, perfect ad blocking or stutter-free playback.
- Skip setup and Not now remain optional; neither opens another permission request on its own. The regular home/header/navigation remains usable. The middle of a library without media permission explains access and offers Allow access.
- Allow access opens Android app permission settings only on tap. Returning after granting permission starts a background library scan. Returning without granting access keeps the explanation; the user may browse other tabs.
- Video and music permissions are separate. Android's selected-video access is respected. All-files access is not demanded merely to view normal media.
- Scanning shows an indeterminate circular animation because providers do not expose a trustworthy total. It never invents a percentage. Cached results stay usable; completion reports the available item count. Incomplete/provider-error scans are not labelled complete.
- First-use swipe guidance is inside each library, double-tap/brightness/volume/HDR guidance is inside an opened video player, and colour-adjustment guidance is inside the HDR customiser. Each has Got it and remembers dismissal. Player controls stay visible while the player guide is pending. Tips are not part of setup.

Validation must cover a fresh install (or cleared app data), skip/deny/grant/revoke/selected-only permission, returning from Settings, narrow/landscape/larger-font layouts, scan failure and background scanning, and first-use guidance dismissal. Existing installations do not repeat the welcome setup just because the copy changed.
