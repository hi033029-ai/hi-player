# Advanced tools — source-only implementation

Status: **uncompiled, tests authored but not run, no device or live-site QA**. No APK/version change, billing, entitlement checks, feature removal, main merge or release is part of this change. Existing features stay unlocked. Build, validation and main merge still require Khan's approval.

## Implemented surfaces

- Settings → Saved playback & theme profiles: up to 24 named configurations. Playback and theme palettes have separate explicit property allowlists and one-transaction application. Absent snapshot fields restore normal defaults. Playback includes video EQ, speed, seek/aspect settings, subtitle style/timing, HDR-enhancement/wide-color switches and night-audio setting. It does **not** capture live GPU grading preset objects, music DSP settings, hardware capability, volume, brightness, account state or permission consent. No credential export/import or cloud sync.
- Music → Equalizer: real Android audio-session Equalizer, five adjustable bands, Flat/Bass/Voice/Rock/Electronic curves. Gains interpolate onto device band frequencies and clamp to the reported hardware range. Session changes reattach the effect; teardown releases it. Selection/custom gains persist. Flat bypasses processing. Unsupported outputs show unavailable rather than pretending effects are active. Removed unsubstantiated “Cinema 3D” / “200%” labels; no surround or loudness claims.
- Browser → Settings → Advanced protection & page skipper: custom hostname block/allow rules, exact-site protection pause, 1×/10×/30×/60× wait-page timer settings and automatic-continue toggle. Native rules publish immutable snapshots; document-start and legacy scripts receive site configuration. No automatic reload/input loss. Explicit blocks override allows and pauses; global ad-blocking off disables the native custom filter too. Host allow rules affect request filtering, not arbitrary cosmetic selectors; use site pause for broken layouts. Changes apply on the next navigation/reload for scripts.
- Files → File tools / selection tools → File organization: selected-file batch rename preview and confirmation (1–200 files, same directory, preserved extension, no directory/hidden/pending-download renames). Exclusive destination creation cannot overwrite existing target files. Copies are synced and the source identity rechecked before removing each original; needs free space and can be slower for large files. This is **not** a transactional all-or-nothing rename; stopping keeps finished operations and can leave a complete copy alongside the original. Do not externally modify files while it runs. Partial/incomplete target cleanup is ownership-checked. Media scanning and library-refresh callbacks follow attempted changes.
- Files duplicate scan: current folder only, at most 2,000 direct files, matching sizes then SHA-256, at most 20 GiB read. No recursion, automatic deletion or device-wide “cleanup.” Changed/unreadable/budget-skipped files produce an explicitly incomplete result. Review only; cancellation never deletes files.
- Settings → account/media sources: up to 12 encrypted Jellyfin/WebDAV connection profiles. Names and credentials reside in the existing Keystore-backed encrypted preferences. Switching re-authenticates Jellyfin or verifies WebDAV before replacing that active source. Failed/cancelled verification leaves the prior active connection; a completed switch is not undone by later cancellation. Generation checks prevent a slow request reconnecting after Disconnect/newer setup. One active connection per source type, not simultaneous federation. Forgetting a saved profile does not disconnect an active copy; disconnecting does not forget saved copies. Google/website sessions are not involved. Device/cloud backup exclusions protect this device-bound store and the existing DataStore containing subtitle credentials.

## Page-skipper safeguards

Timer configuration does not change server time or bypass authentication, payment, consent or security challenges. Sensitive forms/challenge markers stop acceleration and restore normal timer/clock hooks. Existing bounded site detection still decides when timer acceleration is appropriate. Signed YouTube update packages, signature checks, rollback, consent and official sign-in paths are unchanged. No promise of zero ads or equivalence with Brave/uBlock.
