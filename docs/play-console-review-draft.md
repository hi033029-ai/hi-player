# Play Console review preparation — draft, not a submission

Complete and verify these items against the exact release and the owner's actual services before entering anything in Play Console. Google decides whether the app qualifies; do not claim file management, web browsing or any other feature as a core purpose unless it is genuinely central to the product and accurately presented to users.

## Functionality to assess

- **Media library:** the manifest requests `READ_MEDIA_VIDEO`, `READ_MEDIA_AUDIO` and selected visual media access. The video library scans and lists local videos. Explain the actual need for broad video access and why a system picker would not meet that need, if true, in the required declaration.
- **File manager:** the manifest requests `MANAGE_EXTERNAL_STORAGE`; the file manager can browse and manage shared files and folders. Android 11+ access is requested through system settings. Assess whether file management genuinely meets Play's core-functionality standard, whether narrower alternatives suffice, and whether the actual use and user-facing description support a declaration. Approval is not automatic.
- **Package installation:** `REQUEST_INSTALL_PACKAGES` is declared. An explicit file-manager action hands an APK URI to Android's installer; verify all entry points and user consent on device. Play permits certain file-management and browsing use cases only where receiving/sending and user-initiated installation of packages are core functionality. Do not claim eligibility without verifying this and the other policy conditions.
- **Google account / Drive:** Firebase Authentication handles Google sign-in. Optional Drive access requests `drive.readonly`, subject to Google OAuth review. Sign-out is not account deletion. Verify account-creation and account-deletion requirements, in-app and web request paths, retention and actual deletion procedures before submission.
- **Online services:** lyrics searches can send track metadata to LRCLIB and lyrics.ovh. The browser contacts sites and filter-list/update providers, and users may configure other services. Confirm rights, provider practices, settings, retention and any associated SDK data use.
- **Other declarations:** check foreground-service use, notifications, ads, target audience, content rating, reviewer access and the store listing against the final artifact. Complete Data safety from actual collection/sharing practices, including third-party SDKs; locally stored data and information sent to third parties should not be guessed into a form without understanding Google's definitions.
